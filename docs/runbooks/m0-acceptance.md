# M0 驗收步驟（在你的 Mac 上）

需要：Docker Desktop 4.12.0、Chrome 138。主機不用裝 Node。

## 1. 啟動

```sh
git fetch origin
git switch main
git pull
make dev
```

第一次會下載映像和依賴。看到 Vite 的網址後，用 Chrome 開 <http://localhost:5173>。
結束時按 `Ctrl+C`，再執行 `make down`。

## 2. 量效能

1. 接上電源，關掉其他耗資源的程式。
2. 視窗放到平常會玩的大小。
3. 按「量測效能」，約 30 秒。期間讓分頁保持在最上層。
4. 按「複製結果」，整段貼回 PR 或對話。

過關標準：中畫質平均至少 30 FPS。畫面上限通常是 60。
達到上限時，各畫質的數字會一樣，看不出還剩多少餘裕。高、中兩級只差像素比與陰影解析度，
所以 draw call 和三角形數相同；低畫質關掉陰影，兩者約減半。

## 3. 看美術樣張與格線

- 畫面本身就是美術樣張。也試「滿載」、縮放和拖曳。
- 按「格線座標」，和實體棋盤比對：共 133 格；橘色是島嶼 40 格，綠色是安全島上岸格，白圈是海蛇起點。

## 4. 看房間設定說明

按「房間設定說明」。確認沒玩過的人看得懂、知道怎麼選。這裡的選項目前不影響任何東西。

## 5. 開發環境

| 檢查 | 做法 | 預期 |
|---|---|---|
| 改檔即更新 | 改 `apps/web/src/i18n/zh-TW.ts` 的 `appTitle` 後存檔，再改回來 | 幾秒內畫面更新 |
| 容器內完整檢查 | `make check` | 全部通過 |
| Node 24（可選） | `NODE_IMAGE=node:24-alpine make dev` | 一樣能開 |

## 6. 手機（M0 可選，M2 起必做）

手機和 Mac 連同一個 Wi-Fi，執行 `BIND_ADDR=0.0.0.0 make dev`，手機開 `http://<Mac 的區網 IP>:5173`。
這會讓同一網路的人都連得到，只在信任的網路使用，測完改回 `make dev`。
用 `http://` 區網位址時，「複製結果」可能無法使用，請手動選取文字。

## 常見問題

- 5173 被占用：`WEB_PORT=5174 make dev`。
- 建置失敗：把終端機最後 30 行貼回來（先確認裡面沒有個人資訊）。
