# ADR-0003：紙藝 3D 的畫法與效能取捨

- 狀態：已接受（2026-11-27，擁有者核可美術樣張與 Mac 實測 FPS）
- 日期：2026-11-27

## 背景

想要紙藝風格，但基準機是 2014 年的雙核心筆電加內顯，而且桌遊畫面首重看得清楚。

## 決定

- 採用 papercraft 的方法（`.claude/skills/papercraft/`）：有厚度的平面紙片、深色切邊、全霧面、
  一盞暖色主光、帶環境色的陰影。程式與模型自行撰寫，不使用外部圖片。
- 顏色寫在頂點上，全場景的紙片共用一個材質；同形狀用 instancing。
- 畫質三級：像素比上限 1.5／1.25／1.0，陰影貼圖 2048／1024／關閉。
- 目標 draw call 150 以下。
- 高畫質另外開啟地面紙紋（2026-11-28 擁有者提出）：沙礫、草叢、皺紙岩面、海面摺痕。
  中、低畫質不開。原本高、中只差像素比與陰影解析度，肉眼幾乎看不出差別。
  - 紋理由 `paper/surfaces.ts` 產生，不放任何圖片檔。擁有者提供的照片只當參考，不進 repo。
  - 一張 RGBA 資料貼圖，每個色版一種紙紋，只調整明暗，不改配色。每片紙用頂點的
    `surface` 權重指定色版，仍然共用材質，draw call 不變；切換畫質只改一個 uniform。
  - 代價：每個像素多一次貼圖取樣；開啟頁面時多一段 CPU 產生時間（沙盒約 0.2 秒）。
  - 棋子、船、生物本體維持素面，才能從地面跳出來。
  - 紋理有濃淡（2026-11-28 擁有者提出）：棋盤外和已經放了東西的格子接近完整強度，空格子約六成，
    間接提示哪裡有空位。`paper/strengthMap.ts` 依盤面算出一張 256×256 的俯視分布圖，
    交界用雜訊扭曲再模糊，各區內另有深淺起伏；棋子改變時重算。每個像素再多一次貼圖取樣。
  - 擁有者看過三版比較後選定分濃淡，要往提示移動的方向做。目前只看格子上有沒有東西；
    有了 M1 的移動規則後，淡的格子要改成「可以移動到」，M2 做操作提示時接上。
  - 試過兩種做法後放棄：整面紋理用固定的隨機分區調淡到三成以下（擁有者回饋：太多地方像沒有紋理）；
    人物腳下的紙層另外調淡。
- 生物顏色所有版本統一（擁有者裁定）：海蛇紅、鯊魚綠、鯨魚藍、怪獸紫。怪獸模型到 Island 版才做，
  到時要處理它和紫色玩家的區分。
- 每種生物配一個鮮豔的重點色提升辨識度（2026-11-28 擁有者提出），只做點綴：海蛇背鰭是白底加
  順著鰭向的亮紅線，鯨魚水柱是白底加亮藍水流線，鯊魚維持上深下淺的灰綠，亮綠只畫成皮膚反光。
  怪獸和之後的新生物比照辦理。試過整片亮紅、亮藍、亮綠（鯊魚的鰭整片塗亮綠很不像真的鯊魚）。
  `paper/accents.test.ts` 用紙片面積限制彩色的比例。
- 玩家色：橘紅、亮藍、檸檬黃、薄荷綠、亮紫、粉紅。紅偏橘、藍紫調亮，是為了和海蛇、鯨魚拉開；
  黃色跟著改亮，才能和橘色分開。`paper/palette.test.ts` 用 OKLab 色差檢查玩家之間、
  玩家與地面、生物與海面、紅對海蛇、藍對鯨魚。這個測試只看原始色值，不含光影，也沒有檢查色弱視覺。
- 海上生物的紙片往後仰，俯視時看得到側面。要讓生物朝左時用左右鏡射，不能轉 180 度。
- 能在陸上也能在海裡的棋子做兩種外形（2026-11-28 擁有者提出），依所在格子挑一種。人物在陸上
  站在底座上；在海裡和其他海上生物一樣漂浮：只露出上半身，身前有浪、周圍是水波，一手划水。
  之後的兩棲生物比照辦理：用 `paper/pieces.ts` 的 `AmphibiousForms` 型別，兩種外形都要做。
  `paper/amphibious.test.ts` 檢查人物海中外形的露出高度、水波和玩家色。
- 人物盡量不被地形與建物擋住：人物站板塊前半部，樹和山固定在後半部，山用正面朝鏡頭的紙片，
  板塊不旋轉（畫面變化靠多剪幾個版本）。`paper/occlusion.test.ts` 用射線檢查。
  新增板塊裝飾時要一起納入這個測試；船與海上生物的遮擋，等 M1 有載客盤面後再檢查。

## 為了可讀性與舊 GPU 放寬的規則

| papercraft 的做法 | 本遊戲的調整 |
|---|---|
| 移軸景深模糊 | 棋盤全部清晰。M0 不做後製 |
| 畫面內 100–250 件密集物件 | 裝飾集中在安全島，不遮格子與棋子 |
| 地面鋪滿到畫面外、無邊界 | 保留（海面底紙大於任何畫面比例） |
| 鏡頭俯角 40–55 度 | 橫向 56 度、直向 66 度，方便看清格子 |

## 影響

- 原型模型是暫定品質，M6 才做完整美術與動畫。
- 玩家目前只靠顏色區分；色弱友善的第二種辨識方式留到 M6。
