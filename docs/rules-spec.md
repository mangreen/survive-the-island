# Atlantis 規則規格（M1）

引擎照本文件實作；每條規則的測試名稱帶規則編號。條文是用自己的話整理，規則書本身不收進 repo。

來源標記：

- **基**：Survive: Escape from Atlantis! 30 週年版基本規則
- **擴**：同版的 5–6 人迷你擴充
- **裁**：擁有者裁定（含日期）
- **暫 Qn**：規則書沒有寫清楚，先暫定，列在最後的「待裁定」

範圍：基本規則、5–6 人、2 人各執兩色。挑戰規則、海豚與潛水骰、巨型烏賊留到 M8。

## 名詞

- **海格：** 棋盤 133 格中，目前沒有地形板塊的格子（含安全島旁的上岸格）。
- **泳者：** 在海格、不在船上的人物。
- **船上人物：** 在某艘船上的人物。
- **控制船：** 船上人數最多的玩家；平手時，平手的玩家都能控制。空船任何人都能移動。
- **暫存區：** 尚未上場的船、鯊魚、鯨魚。離場的棋子不回暫存區。

## 隱藏資訊

引擎只能透過 `viewFor(玩家)` 輸出畫面資料，事件也要依觀看者過濾。

| 編號 | 誰看得到 |
|---|---|
| HID-1 | 還沒拆的板塊背面：沒有人 |
| HID-2 | 手牌內容：只有持有者；其他人只看得到張數 |
| HID-3 | 人物分值：布置階段只有本人看得到「還沒放的分值」；放下後沒有人看得到；終局公開獲救者分值 |
| HID-4 | 亂數種子和亂數狀態：沒有人（看得到就能推出所有隱藏資訊） |
| HID-5 | 公開：地形種類、棋子位置與顏色、骰子結果、已打出和立即翻開的板塊 |

## 引擎要求

- ENG-1：純函式「狀態＋動作 → 新狀態＋事件」，不碰 DOM、網路、時間，不用 `Math.random`。
- ENG-2：設定＋種子＋動作日誌能完整重建一局。
- ENG-3：等待中的決定（防禦回應、擠船選人）記在狀態裡，換房主能從同一點接續。
- ENG-4：事件附原因代碼（之後的提示與教學要用）。
- ENG-5：不合法的動作一律拒絕並回傳原因代碼，狀態不變。
- ENG-6：種子是 128 位元，由房主用安全亂數產生。地形排列是公開的，又和板塊背面出自同一個種子；32 位元的種子可以窮舉比對地形，反推出全部背面。

## 待裁定

以下先照「暫定」實作。回覆「照暫定」就全部接受；平衡測試後仍可調整。

| 編號 | 問題 | 暫定 | 另一種做法 |
|---|---|---|---|
| Q1 | 泳者「每回合移動一次」怎麼算？ | 游到相鄰格、上同格的船、跳下船、上安全島，每種都算那一次（所以不能先游再上船，這點照規則書）。從海裡上船的人，這回合不能再自己移動，但可以隨船走。開船撞鯨魚而落水、還沒用過那一次的人仍可移動 | 上船後就照一般船上人物處理，可以再換船或上岸 |
| Q2 | 人物上到停在海蛇或鯨魚同格的空船，會被攻擊嗎？ | 不會；之後生物移入或這艘船開進去才觸發 | 一上船就觸發 |
| Q3 | 海豚、船移動板塊怎麼走？佔用泳者那次移動嗎？ | 一格一格走，途中被攻擊就停；只能走海格（不能直接上岸或上船）；不佔步驟二的移動 | 直接跳到終點 |
| Q4 | 「移動你控制的船」包含空船嗎？ | 包含 | 只限船上有你且由你控制 |
| Q5 | 獵捕鯨魚的「你的船」指什麼？多人都能防禦時呢？ | 船上有你任何一人就算；依回合順序詢問，第一個使用的人生效 | 只限你控制的船 |
| Q6 | 生物可以走回頭路，例如走兩格回到原位？ | 可以 | 每一步都不能回到走過的格子 |
| Q7 | 2 人各執兩色的細節？ | 每色 2 艘船（共 8 艘）；一回合可混用兩色，仍是 3 點移動、1 片手牌；控制船時兩色人數合併計算；布置時兩人輪流，每次放 1 人，顏色自己選 | 兩色分開輪流，當成 4 個座位 |
| Q8 | 自然模式的「領先者」怎麼算？60% 怎麼套用？ | 領先者＝獲救人數最多，同數看場上剩餘人數。有可攻擊的走法時 60% 攻擊（優先打領先者），其餘情況在不攻擊的走法（含不動）中隨機挑 | 之後依試玩調整 |
