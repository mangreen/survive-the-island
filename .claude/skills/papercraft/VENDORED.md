## 審視範圍

做過的事：用關鍵字掃描程式與文件（對外連線、動態執行、子程序、憑證相關字眼、隱藏字元、超長行），
並閱讀 `SKILL.md` 的主要段落與腳本中啟動子程序、刪檔、開伺服器的段落。結果：

- HTML 範本用 jsDelivr CDN 載入 three.js。本遊戲用 npm 打包，不使用這些範本的載入方式。
- `scripts/capture.py` 會開一個只綁 `127.0.0.1` 的本機伺服器、呼叫 `ffmpeg`，並刪除自己輸出資料夾裡的舊影格。
- 沒有看到可疑的對外連線或要求 Agent 做額外操作的指示。

**這不是逐行的安全稽核。** 執行 `scripts/` 下的程式前，先確認它要讀寫哪些路徑。
更新版本時，重新做一次同樣的檢查。

## 使用方式

本專案把它當美術方法與參考，不要求照單全收。為了桌遊可讀性與舊 GPU，
放寬的規則寫在 `docs/adr/0003-rendering-papercraft.md`。與專案規範衝突時，以 `AGENTS.md` 為準。
